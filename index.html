Seven tools that do the busywork

Each button takes one repetitive job and finishes it in a few seconds, right inside Revit.

01

Doors & Windows

See and manage every door and window in the model from one panel.

 02

Tags

Tag doors and windows across your views in one pass, not one at a time.

 03

Dimensions

Draw wall and grid dimension strings, wall end to each opening to wall end.

 04

Create the four interior elevations for a room, finish face to finish face.

 05

Place a callout around each room, sized to the room and named after it.

 07

About

Built by an architect, for the people doing the drawings

I'm Vivek M.S., an architect and BIM specialist based in India. I spend most of my day in Revit. MSV started as a set of personal tools to get through the repetitive parts of documentation, and it grew into a plugin worth sharing.

I'm adding an AI assistant to MSV, built on Claude through the Anthropic API, that answers Revit questions and helps run tasks inside your model. It is in development. I'm also building Revit AI, a team of Claude agents that model, document and check projects inside Revit. It is in testing, and project data stays on your own disk.

The idea is simple: take the jobs that are slow and easy to get wrong, and hand them to a button. Found a bug or want a tool added? Write to vivek@msvplugin.com or find me on LinkedIn.
