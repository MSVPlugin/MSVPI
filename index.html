The MSV tab

Seven tools that do the busywork

Each button takes one repetitive job and finishes it in a few seconds, right inside Revit.

Doors & Windows

See and manage every door and window in the model from one panel.

Tags

Tag doors and windows across your views in one pass, not one at a time.

Dimensions

Draw wall and grid dimension strings, wall end to each opening to wall end.

Interior Elevations

Create the four interior elevations for a room, finish face to finish face.

Room Callouts

Place a callout around each room, sized to the room and named after it.

Sheet Gen

Replicate sheets and views per trade, then find-and-replace the numbering.

QC

Scan the documentation for issues before you issue a set.

Tutorials

Watch how each tool works

Short, practical walkthroughs on the MSV YouTube channel: installing the plugin and using each command on a real model. New videos every week.

About

Built by an architect, for the people doing the drawings

I'm Vivek. I work in architecture and BIM, and I spend most of my day in Revit. MSV started as a set of personal tools to get through the repetitive parts of documentation, and it grew into a plugin worth sharing.

The idea is simple: take the jobs that are slow and easy to get wrong, and hand them to a button. Found a bug or want a tool added? Get in touch.
